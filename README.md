# 🐾 Dieren Memory

Een kindvriendelijk memory-spel voor twee spelers, gebouwd met Streamlit.
Vind alle 32 dierenparen op een 8×8 bord!

## Vereisten

- Python 3.9 of hoger
- pip

## Installatie & starten

```bash
# 1. Installeer de benodigde packages
pip install -r requirements.txt

# 2. Start de app
streamlit run app.py
```

De browser opent automatisch op `http://localhost:8501`.

## Packages

| Package | Versie | Waarvoor |
|---------|--------|----------|
| streamlit | ≥ 1.32 | Volledige app-interface |

Alle andere gebruikte modules (`random`, `time`) zijn standaard Python.

## Hoe speel je?

1. Open de app in je browser.
2. Speler 1 begint: klik op twee kaarten om ze om te draaien.
3. **Paar gevonden?** De kaarten blijven open en je mag nog een keer!
4. **Geen paar?** Klik ergens om de kaarten terug te draaien. Speler 2 is aan de beurt.
5. Houd bij wie de meeste paren vindt — die wint! 🏆
6. Klik op **"Nieuw spel"** om opnieuw te beginnen.
